# Propuesta landing page PING

Propuesta de sitio web para **PING SA · Printer Solutions**: outsourcing de impresión, outsourcing informático y venta de equipos para oficina.

**Ver la propuesta:** abre `index.html` o la versión publicada en GitHub Pages.

## Contenido

- `index.html`: boceto navegable de las cuatro páginas (Inicio, Servicios, Nosotros y Contacto). Es responsive.
- `elementor/`: código de cada página para pegar en un widget HTML de Elementor.
- `imagenes/`: logo horizontal, ícono e imagen de producto.
- `LEEME.md`: pasos para montar el sitio en WordPress.

Los datos de contacto y algunos textos son de ejemplo y están marcados para reemplazar.
